# 🚀 概述

Better Entity Render 是一个 Minecraft 实体渲染优化模组。

通过原生代码加速和智能算法优化，大幅提升实体渲染性能，同时保持完美的视觉表现。在大量实体场景下可带来 **20%~33%** 的显著帧数提升，尤其适合大型刷怪场、复杂建筑、多人服务器等高负载环境。


# ✨ 核心特性

## 🎯 智能遮挡剔除

- 动态视锥体裁剪：自动剔除视野外的实体，减少无效渲染
- 方块遮挡检测：被方块完全遮挡的实体直接跳过渲染，减轻 GPU 压力
- 可配置检测距离：支持自定义最大检测距离，平衡性能与效果
- 玩家豁免：不会错误剔除玩家实体，保证游戏体验

## 🌟 阴影渲染重构

- 原生计算加速：使用 C++ 重写阴影计算，充分发挥硬件性能
- 智能缓存系统：同一实体同帧内阴影复用，避免重复计算
- 提前过滤：无效阴影块在 Native 层直接剔除，减少内存操作
- Windows 平台专属优化：在其他系统上自动降级，不影响稳定性

## ⚡ 碰撞检测优化

- 一次收集，多次复用：将三次碰撞检测的方块收集合并为一次，大幅减少计算量
- 智能步高处理：优化上坡时的碰撞检测逻辑，减少冗余查询
- 世界边界优化：只在必要时处理世界边界碰撞，节省无效开销

## 📦 VoxelShape 缓存

- AABB 缓存机制：每个 VoxelShape 的包围盒只计算一次，避免重复计算
- 大幅降低 bounds() 调用开销，提升碰撞箱计算效率
- 透明兼容：完全兼容其他模组，无冲突风险

## 🔧 基础优化

- 相机位置缓存：每帧只获取一次相机坐标，消除 Vec3 对象分配，减少 GC 压力
- Chunk 列缓存：同一 Z/X 列共享 ChunkAccess，减少重复获取，提升区块访问效率
- 位运算优化：使用浮点位操作传递整数坐标，避免类型转换开销

## 🎮 LOD 细节层次优化

- 智能细节削减：远处实体自动剔除次要模型部件（帽子、耳朵、第二层皮肤等）
- 动画冻结：远处实体冻结动画/姿势更新（setupAnim），大幅节省 CPU
- 特效跳过：远处实体跳过昂贵渲染层（发光、光晕轮廓等）
- 玩家豁免：玩家不受 LOD 影响，始终以完整细节渲染
- 连续过渡：细节变化平滑无闪烁，视觉体验良好


# ⚙️ 配置选项

所有功能均可独立开关，支持实时调整（需重启游戏）。

```toml
[shadow]
    # 启用硬件加速的阴影渲染
    enabled = true

[occlusion]
    # 跳过完全被固体方块遮挡的实体渲染
    enabled = true
    # 遮挡检测的最大距离（格）。超出此距离的实体将跳过遮挡检查直接渲染。
    # 设为 -1 表示无限（检测所有实体）。
    # 范围: -1.0 ~ 512.0
    maxDistance = -1.0

[collision]
    # 减少台阶高度路径中冗余的方块碰撞查询
    enabled = true

[lod]
    # 降低远处实体的渲染精度（连续变化，无闪烁）：
    # 剔除次要模型部件、冻结动画、跳过昂贵的渲染层
    enabled = true
    # 隐藏远处实体的次要模型部件（覆盖层/第二层皮肤、帽子、耳朵等）
    cullParts = true
    # 超出此距离（格）后，次要模型部件将被隐藏
    # 范围: 0.0 ~ 512.0
    detailDistance = 32.0
    # 跳过远处实体的动画/姿势设置（setupAnim），以节省 CPU
    freezeAnim = true
    # 超出此距离（格）后，动画将被冻结
    # 范围: 0.0 ~ 512.0
    animDistance = 48.0
    # 跳过远处实体的昂贵渲染层（发光/光晕轮廓效果等）
    skipEffects = true
    # 超出此距离（格）后，昂贵渲染层将被跳过
    # 范围: 0.0 ~ 512.0
    effectDistance = 24.0
    # 为 true 时，玩家将不受 LOD 影响，始终以完整细节渲染
    skipPlayers = true
